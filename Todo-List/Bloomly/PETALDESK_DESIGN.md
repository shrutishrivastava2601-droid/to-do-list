# PetalDesk visual update

The existing task-management functions and JavaScript architecture were preserved.
Only the visual identity was updated:
- Rebranded from TaskFlow to PetalDesk.
- Light mode uses a baby-pink / blush palette.
- Dark mode uses a deep rose-pink palette so the theme remains pink in both modes.
- Responsive behavior and existing controls are retained.
- No external UI template or copied reference layout was introduced.
